为什么放在编辑器里

少开一个浏览器标签页：查个编码、算个哈希、格式化一段 JSON，都不用离开代码。

侧边栏一键进入

活动栏新增 Magic Tools 图标，搜索框 + 分类折叠，敲两个关键字就能定位工具；折叠状态会记住。

编辑器里独立面板

每个工具在编辑器区打开一个面板，可并排、可拆分、可与代码对照；同一工具重复打开只聚焦已有标签。

9 类共 119 个工具

类型转换、编解码、加解密、值计算、格式化、图片、生成器、站长工具、其它，迁移自 magic-tools 桌面版。

全本地运行

Web Crypto、crypto-js、WebAssembly 全部在 WebView 内跑，没有服务端，不采集任何数据。

跟随编辑器主题与语言

用 --vscode-* 变量配色，深浅色 / 高对比度主题自动同步；界面支持简体、繁体与英文。

缺少的能力走宿主桥

DNS 查询、MTR、Whois、网页抓取等浏览器做不了的事，由扩展宿主用 Node 执行（见 网络能力）。

安装

需要 VS Code 1.75 及以上版本。三种方式任选其一。

1

应用市场安装

在扩展面板搜索 Magic Tools，或直接点下面的按钮。

打开 Marketplace

使用 VSCodium / code-server 等可以从 Open VSX 安装。

2

命令行安装

已经装好 code 命令的话，一行搞定：

code --install-extension freewu.magic-tools-vscode
3

离线 VSIX

内网 / 断网环境：下载 magic-tools-<version>.vsix 后本地安装。

下载最新 .vsix

code --install-extension magic-tools-1.4.0.vsix

装好之后

  1. 点左侧活动栏的 Magic Tools 图标（或命令面板 视图: 显示 Magic Tools）。
  2. 在侧边栏搜索工具，点击即会在编辑器区打开面板。
  3. 用 Ctrl + Alt + P 之类的自定义快捷键绑定命令 magic-tools.open 也能直接打开侧边栏。

网络能力（宿主桥）

有些工具浏览器做不了（原始 DNS、ICMP、TCP Whois、跨域抓取）。扩展宿主用 Node 内置模块实现了同名命令，webview 通过消息桥调用，因此这些工具在扩展里同样可用。

命令 宿主实现 说明
dns_query 自组 DNS 报文 → UDP 53，截断时改 TCP 保留真实 TTL 与否定应答 SOA，支持 A / AAAA / CNAME / MX / TXT / SRV / NS / SOA / PTR / CAA
reverse_dns dns.promises.reverse MTR 逐跳名称解析
whois_query TCP 43 + refer: 逐级转介 最多 3 跳，内置常用 TLD 服务器表
mtr_probe 系统 ping 的 TTL 参数逐跳探测 计时口径与真实 ICMP 略有差异；仅支持 IPv4 目标
fetch_url_body http/https + gzip/deflate/br 绕过 CORS，3MB 上限、20 秒超时，字符集由前端探测

纯浏览器环境（npm run dev:web）没有宿主，这些工具会显示「仅桌面版可用」提示并给出下载入口。

本地开发

仓库用 GitHub 托管，构建脚本收敛在 just / npm 里。

常用命令

just install # 安装依赖
just dev # 构建并打开扩展开发宿主
just dev-web # 只跑前端 http://localhost:1212
just verify # 类型检查 + 冒烟测试 + 构建
just package # 生成 .vsix
just docs # 重新生成本站

工程结构

src/extension.ts 宿主: 侧边栏 / 面板 / 网络命令桥
src/net/ 宿主网络能力实现
webview/src/App/ 119 个工具 (每个目录一个)
webview/src/shell/ 外壳与工具注册表
docs/ 本站 (GitHub Pages)
scripts/ 冒烟测试 / 本站生成
新增一个工具需要做什么
  1. 在 webview/src/App/<ToolKey>/ 放 define.tsx（AppName / Icon / Type）与 index.tsx。
  2. 注册表通过 import.meta.glob 自动发现，无需改代码；分类在 webview/src/shell/registry.ts 的 APP_TYPES 里。
  3. 跑 npm test（jsdom 会把每个工具页面渲染一遍）与 just docs 更新本站清单。
